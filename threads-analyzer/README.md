# Threads 投稿分析ツール

Threads のアカウント URL を渡すと、**直近 6 か月の投稿**を集めて分析用の Excel を出力します。

```bash
python threads_export.py https://www.threads.com/@username
# → output/threads_username_20261113.xlsx
```

## 出力される Excel

| シート | 内容 |
|---|---|
| **サマリー** | 全体 KPI（合計・平均・最大）、曜日別・時間帯別の平均エンゲージメント（グラフ付き）、月別推移、エンゲージメント上位 10 投稿、ハッシュタグ別ランキング |
| **投稿一覧** | 1 投稿 1 行：投稿日時 / 曜日 / 時台 / 本文 / 文字数 / ハッシュタグ / いいね / 返信 / リポスト / 引用 / シェア / ブックマーク / 表示回数 / エンゲージメント合計 / エンゲージメント率 / メディア / URL（フィルター・ウィンドウ枠の固定済み） |
| **取得情報・注意事項** | 取得条件、取得できなかった項目とその理由、各列の定義 |

サマリーは数式で `投稿一覧` を参照しているので、行を削除・修正すると集計も自動で更新されます。

## 2 つの取得モード

Threads の仕様上、**取得できる項目はアカウントによって変わります**。

| 項目 | ① 公式 API モード（自分のアカウント） | ② ブラウザモード（どのアカウントでも） |
|---|:-:|:-:|
| 本文・投稿日時・URL・ハッシュタグ | ✅ | ✅ |
| いいね・返信・リポスト・引用・シェア | ✅ | ✅ |
| **表示回数** | ✅ | ❌（本人以外には非公開） |
| **ブックマーク（保存）数** | ❌（API に項目なし） | ❌（本人以外には非公開） |

- `--mode auto`（既定）：アクセストークンがあり、それが指定アカウント本人のものなら ①、それ以外は ②。
- 取得できない項目は Excel 上で空欄になり、「取得情報・注意事項」シートに理由を記載します。

> ブックマーク数は 2026 年 11 月時点で Threads 公式 API に存在せず、Web 上でも本人以外には公開されていません。自分の投稿の保存数は Threads アプリのインサイト画面で確認できます。

## セットアップ

Python 3.10 以上が必要です。

```bash
cd threads-analyzer
pip install -r requirements.txt
playwright install chromium        # ブラウザモードを使う場合
```

### ① 自分のアカウントを分析する（推奨：表示回数も取れる）

1. [Meta for Developers](https://developers.facebook.com/apps/) でアプリを作成し、ユースケースに **「Threads API にアクセス」** を選ぶ
2. 権限 `threads_basic` と `threads_manage_insights` を追加
3. 「役割」→ 自分の Threads アカウントを **Threads テスター** に追加し、Threads アプリの「設定 → アカウント → ウェブサイトのアクセス許可 → 招待」で承認
4. 「ユーザートークン生成ツール」でアクセストークンを発行（長期トークンなら 60 日有効）
5. 実行：

```bash
export THREADS_ACCESS_TOKEN="発行したトークン"      # Windows: set THREADS_ACCESS_TOKEN=...
python threads_export.py https://www.threads.com/@自分のユーザー名
```

### ② 他のアカウント（競合・参考アカウント）を分析する

ログインしていないと直近 20〜30 件ほどしか表示されないため、最初に一度だけログインします。

```bash
python threads_export.py --login       # ブラウザが開くのでログイン → ターミナルで Enter
python threads_export.py https://www.threads.com/@参考にしたいアカウント
```

ログイン情報は `.threads_session/state.json` に保存されます（Git には含まれません。他人に渡さないでください）。

## オプション

| オプション | 説明 |
|---|---|
| `-o 出力.xlsx` | 出力先ファイル名 |
| `--months 3` | さかのぼる月数（既定 6） |
| `--mode api / browser` | 取得モードを固定する |
| `--token XXX` | アクセストークンを直接指定 |
| `--show-browser` | 取得中のブラウザ画面を表示する（動作確認用） |
| `--tz Asia/Tokyo` | 出力する日時のタイムゾーン |

環境変数 `THREADS_CHROMIUM_PATH` に Chrome / Chromium の実行ファイルのパスを入れると、そのブラウザを使います。

## 注意事項

- 数値はすべて**取得した時点**の値です。定期的に取得してファイルを比較すると伸び方を追えます。
- ブラウザモードは、ログイン中のブラウザで画面をスクロールしたときに Threads が返すデータを読み取る仕組みです。Threads の画面やデータ構造が変わると動かなくなることがあります。
- Meta の利用規約は、許可のない自動データ収集を制限しています。ブラウザモードは個人の分析の範囲で、少ない頻度で使ってください。自分のアカウントは公式 API モードを使ってください。
